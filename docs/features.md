# EmotiCare Features

## Overview

EmotiCare integrates multiple emotional and mental health support functions within a single web-based platform.

The platform is designed to support emotional self-awareness, continuous monitoring, digital reflection, wellness engagement, and access to appropriate support.

---

## 1. Emotional Assessments

EmotiCare provides multiple structured emotional and psychological assessment modules.

Available assessments include:

- DASS-21
- SSEIT

Users complete assessments one question at a time.

An answer must be selected before the user can proceed to the next question.

After completing an assessment, the platform calculates and presents the relevant result based on the assessment's scoring method.

---

## 2. Mood Check-In

The Mood Check-In feature allows users to record their current emotional state.

Users can:

- Select a mood level
- Select a relevant feeling
- Record their current emotional state
- Review recent mood information
- Observe emotional changes over time

A valid mood selection is required before the mood can be submitted.

---

## 3. Digital Journaling

The Digital Journaling feature provides users with a space to record personal reflections and emotional experiences.

Journal entries can be integrated with the AI-assisted emotional analysis process to provide additional emotional information and support.

---

## 4. AI-Assisted Emotional Analysis

EmotiCare incorporates AI-assisted analysis for journal text.

The high-level process includes:

1. Journal input
2. Sentiment analysis
3. Text feature extraction
4. Emotion classification
5. Intervention determination

The current workflow incorporates VADER, TF-IDF, and Logistic Regression.

---

## 5. Wellness Activities

The platform provides wellness-oriented activities that users can access as part of their emotional-care experience.

Activities support continued engagement with the platform and provide additional resources for emotional well-being.

---

## 6. Mind Games

EmotiCare includes interactive mind games as an additional engagement component.

The games provide users with another way to interact with the platform alongside assessment, mood, journal, and wellness functions.

---

## 7. Results and Emotional Progress

Assessment results are presented through dedicated result interfaces.

Users can review relevant assessment information and monitor their emotional information across their interactions with the platform.

---

## 8. Result Hub

The Result Hub provides a central location for users to access and review their assessment results.

This brings multiple assessment results together within a unified interface.

---

## 9. Game Hub

The Game Hub provides a central interface for accessing available interactive games within EmotiCare.

---

## 10. Support and Intervention

EmotiCare provides pathways to appropriate support when required.

Depending on the emotional information identified by the platform, the system can support different intervention pathways.

The platform is intended to support users and complement human emotional-care services rather than replace professional or human support.

---

## 11. User Authentication

EmotiCare provides controlled access to the platform through user authentication.

Authentication-related functions include:

- Account login
- Account verification
- Login attempt controls
- Session management
- Session timeout
- Passkey / WebAuthn support

---

## 12. Responsive Web Interface

EmotiCare is designed as a responsive web platform.

The interface supports access through:

- Desktop computers
- Tablets
- Mobile devices

The responsive approach allows users to access EmotiCare through a web browser without requiring a separate mobile application.

---

## Human-Centered Approach

The platform combines four core concepts:

```text
ASSESS + MONITOR + ANALYSE + SUPPORT
```

These functions are integrated within one digital environment to support a continuous and user-centered emotional-care experience.
